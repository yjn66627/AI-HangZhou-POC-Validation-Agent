# public_artifacts｜可公开资产

本目录存放**经过公开审核**、可对外展示的项目资产。

---

## 一、目录用途

用于集中管理对外可见的非源码资产，例如：

- 架构示意图
- 流程示意图
- UI 设计稿与截图
- Demo 演示素材
- 比赛展示用图表

---

## 二、准入规则

放入本目录的内容必须同时满足：

- [ ] 不含任何凭据、令牌、口令、验证码
- [ ] 不含内部原始证据或未脱敏响应报文
- [ ] 不含本机绝对路径
- [ ] 不含个人邮箱、登录账号等信息
- [ ] 不含内部服务地址（域名、内网地址、端口）
- [ ] 图中文字与 Decision Engine 结论档位一致

详见 [`../docs/PUBLICATION_POLICY.md`](../docs/PUBLICATION_POLICY.md)。

---

## 三、建议结构

```
public_artifacts/
├── architecture/     架构图
├── flow/             流程示意图
├── ui/               界面设计稿与截图
└── demo/             演示素材
```

子目录在**首次有实际内容时**再创建，避免制造空目录。

---

## 四、图片处理注意

截图类资产尤其容易泄漏，提交前请逐项检查：

- 浏览器地址栏（可能含内部域名或参数）
- 开发者工具面板（可能含认证请求头）
- 控制台日志（可能含本机路径）
- 输入框中的示例数据（可能含真实信息）

**建议：截图前先清理界面，或对敏感区域做不透明遮挡后再提交。**
