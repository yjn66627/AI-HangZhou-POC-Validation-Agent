# 独立测试部署恢复说明

部署前保存自己环境的函数代码版本、运行时参数、路由目标与鉴权配置；备份应在私有安全存储中，不提交到仓库。本仓库不包含现有项目的可恢复凭据或资源状态。

若合成示例新部署不符合预期，先停止测试流量，再通过云平台把自己的测试路由恢复到已确认的前一函数版本；如前一环境尚未建立，则移除自己新增的测试路由并保留排障记录。凭据通过安全配置界面管理，不从源码或日志恢复。恢复后分别检查路由、401 拒绝行为和经授权的合成响应。

任何涉及既有线上函数、腾讯元器 Tool、CloudBase Gateway 或真实演示的回退，都必须由该环境负责人另行批准并操作。本候选生成过程未进行这些操作。
