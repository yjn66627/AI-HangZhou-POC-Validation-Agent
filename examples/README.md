# examples｜可公开示例

本目录存放**可公开的运行示例**，用于说明如何调用与使用本项目的能力。

---

## 一、目录用途

- 演示典型 Case 的输入形式
- 演示公开 Schema 的使用方式
- 提供最小可运行示例

---

## 二、准入规则

- [ ] 示例中的**全部**密钥类字段使用假值
- [ ] 示例地址一律使用占位域名，不使用真实服务地址
- [ ] 不含内部原始证据
- [ ] 不含本机绝对路径
- [ ] 不含真实业务数据

详见 [`../docs/PUBLICATION_POLICY.md`](../docs/PUBLICATION_POLICY.md)。

---

## 三、示例配置的写法

如果示例需要配置文件，请提交 `.env.example`（**已被 `.gitignore` 白名单放行**），且全部使用假值：

```
# 全部为尖括号占位符，请勿填入真实凭据
变量名=<在此填写你自己的值>
服务地址=<在此填写你自己的地址>
```

**不得提交**真实的 `.env` 文件。

---

## 四、建议结构

```
examples/
├── basic/            最小示例
├── case-inputs/      典型 Case 输入样例
└── schema/           公开 Schema 使用示例
```

子目录在**首次有实际内容时**再创建。
